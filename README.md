## Expert System for Assessing Individual Investment Risk Profiles Based on Investor Characteristics Using the Forward Chaining and Certainty Factor Methods
<p style="text-align: justify">Proyek ini bertujuan membangun sistem pakar dalam penilaian profil risiko investor berdasarkan karakteristik investor tertentu. Proyek ini menggabungkan metode sistem pakar Forward Chaining untuk melacak aturan karakteristik investor dan Certainty Factor (CF) untuk mengakomodasi tingkat keyakinan atau ketidakpastian dalam menentukan hasil profil risiko tersebut.</p>

<p style="text-align: justify">Sistem ini diimplementasi dalam bentuk website yang memungkinkan pengguna dapat mengakses melalui cross-platform seperti Android, ioS, dan Desktop </p>

## INSTALASI
Clone repository menggunakan terminal 
```bash
git clone https://github.com/alcamic/expert_system_investor.git
```
Buat Virtual Environment Python ([pip](https://pip.pypa.io/en/stable/)) setelah melakukan Clone Repository.
```bash
python -m venv [name_virtual_environment]
```
Aktifkan Environment untuk download library dan menjalankan app.
```bash
[name_virtual_environment]/Scripts/activate
```
Download library yang sudah berada di ```requirements.txt```
```bash
pip install -r requirements.txt
```
## PENGGUNAAN
Jalankan ```app.py```
```bash
python app.py
```
